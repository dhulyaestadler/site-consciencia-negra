# Perfil de Rede Social - VSCode Project

Este projeto contém a estrutura completa para uma interface de perfil de rede social responsiva com suporte a 20 posts, alternância de visualização em grade/feed corrido e modo escuro.

## 📁 Estrutura de Arquivos
- `index.html`: Estrutura da página HTML.
- `style.css`: Estilização e suporte ao tema escuro.
- `script.js`: Dados e lógica de interação.

## 🛠️ Como Personalizar

Abra o arquivo `script.js` no seu VSCode:

1. **Informações do Perfil**: Edite a constante `PROFILE_DATA` no topo do arquivo `script.js`.
2. **Fotos e Legendas dos 20 Posts**: Edite o array `POSTS_DATA` em `script.js`. Substitua o campo `imageUrl` pelo link das suas imagens e `caption` pelas suas legendas.
